# Einbürgerungstest 关键词速记表（310 题 · 中德对照）

> **怎么用**：考试是单选，你要的是「看到题 → 认出正确答案的样子」。第 4 列**德文正确答案**才是真正要刻进肌肉记忆的东西，第 3 列「题干锚点」只是帮你认出这是哪道题的钩子。


**技巧标签**
- `否定` 题干有 nicht / kein / keine → 选那个"不合群/坏的"答案，逻辑是反的。
- `数字` 答案是数字/年份/年龄/百分比 → 死记数字锚点。
- `价值观` 答案在讲自由/民主/平等/人的尊严 → 拿不准时优先选这类。
- `图片` 看图选编号，纯视觉记忆，必拿分。
- `配对` 普通题，靠题干锚点 ↔ 答案锚点的形状配对。
