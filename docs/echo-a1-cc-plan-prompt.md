## 产品背景（已定结论，不重新讨论）

A1 课程是「A1 学习协议 v0.2」的 Echo 实现。协议目标：成年自学者（v1 画像：中文母语、英语基础、每天约 2 小时）在 60–150 真实小时内达到 Goethe A1 数字版考试就绪（≥60/100，内部目标 ≥75）。

**八条承重墙原则**（所有功能必须满足，冲突时按此裁决）：
1. 输入可理解（i+1）
2. 复习即检索（不重读）
3. 形态匹配：识别练识别、产出练产出
4. 输出有纠错闭环：错误自动入错题卡组
5. 即时反馈：每个练习动作反馈延迟趋近零
6. 摩擦预算：后勤摩擦 → 0（打开即练、无需决策）；认知摩擦校准到能力边缘
7. 依从性优先：与理论最优冲突时，选执行率
8. 防 Goodhart：应试训练 ≤15% 总学时

## 功能需求（按模块）

### M1 · 课程骨架与每日会话编排器（Session Composer）
- A1 课程分三阶段：冷启动 / 主建设 / 考试特化。
- 每日会话按学时预算自动编排，默认比例（总量约 120h，可配置）：可理解输入 48 / SRS 24 / 输出+反馈 20 / 应试形态 12 / 语音 HVPT 8 / 真实使用 4 / 复盘缓冲 4。
- 标准日约 2h，拆两段；**最低可行日（MVD）≈ 20 分钟** = 一轮 SRS 完成 + 一条可理解输入 + 一句录音输出。MVD 是 streak 的计入单位。
- 打开即练：进入 app 直接呈现"今天的下一个动作"，零配置、零决策。

### M2 · 依从性层【最高优先】
- streak 绑定 **MVD 完成**（学习加权），不绑定打开 app。
- 每月 2 个宽限日 + 自动冻结；可见进度永不清零；中断修复文案用"新起点"框架（下周一/月初重启点）。
- 上手流程强制 if-then 执行意图：模板"___之后，我就在___做 20 分钟德语块"，可挂本地提醒。
- 进度可视化以**累积能力**为主（已掌握词数、检查点分项分、分类累计学时），连续天数为辅。
- 指标埋点：执行率（实际/计划学时）、最长中断天数、MVD 触发次数。

### M3 · SRS（词汇 + 句型）
- 调度算法 FSRS；目标保留率默认 0.88，提供"忙碌模式" 0.85。
- 卡模板：名词卡**冠词与复数为必填字段**；der/die/das 与句型卡按标签**交错调度**，不分块。
- 内容：Goethe A1 词表（约 650 词）种子卡组 + 句子岛挖空（cloze）卡。
- 新词节流与阶段联动：冷启动 20–25/日 → 主建设 15/日 → 考前 10 天停新词、只清复习债。

### M4 · 听写模式（Diktat）
- 播放句音频 → 用户键入 → 字符级 diff 高亮 → 即时判定。
- 句长爬坡：当前长度连续 N 条 ≥90% 字符准确率则升级，失败自动回退（认知摩擦校准的可操作化）。
- 数字子模式：电话号码 / 价格 / 钟点专项。
- 所有错误自动结构化生成错题卡入 SRS。

### M5 · 输出闭环
- 每日产出任务：用当日词汇回答问题 / 写约 30 词短消息（内置"三要点覆盖"自查）。
- LLM 反馈规格：**显性纠错**（非含蓄 recast）、拒绝认可病句、即时返回。
- 每个错误结构化 → 错题卡自动入 SRS（与 M4 共用管道）。

### M6 · 口语栈
- HVPT 感知训练：ü/ö、长短元音（Stadt/Staat 类）、词尾清化的最小对立对辨认；多说话人音源；即时对错反馈。
- LLM 语音陪练编排：跟读 → 复述 → 4/3/2 会话流程；系统提示词强制显性纠错。
- **明确不做：发音打分/评级**（CAPT 精度不足以支撑产品，此 scope 禁止进入计划）。

### M7 · 仪表与检查点
- 七类学时日志（按活动类型自动归类，无手动记录负担）。
- 检查点：3 次全真模拟的分项分录入与趋势视图。
- SRS 成熟卡保留率报表。

## 非目标（明确不做）
- 发音自动评分器
- A2 及以上内容
- 社交/排行功能
- 超出 15% 学时占比的应试题库堆砌

## 硬约束
- 遵守 CLAUDE.md 宪法：零配置默认、本地优先（学习数据与日志本地存储优先）、可插拔中间件。
- PWA 离线可用：SRS 与听写必须离线可用；LLM 依赖类功能（M5/M6 陪练）需在线，设计离线降级。
- 复用优先：先盘点现有 sentence islands、shadowing、SRS、error deck、Leben in Deutschland 题库的既有实现与数据模型，能复用不新建。

## Plan 模式产出要求

1. **代码库勘察结论**：现有模块/数据模型与 M1–M7 的映射表；可复用清单；缺口清单。
2. **数据模型提案**：课程 / 阶段 / 每日会话 / 活动 / 卡片 / 学时日志 / 检查点的 schema 草案（含与既有模型的兼容策略）。
3. **分阶段实施计划**，每阶段可独立交付、以"n=1 用户立即可用于备考"为排序标准。建议参考（可基于代码库现实调整，但需说明理由）：
   - **P0**：M3 SRS 强化（FSRS 0.88、冠词必填、交错）+ M4 听写全量 + M2 最小版（MVD 定义 + streak + 宽限日）
   - **P1**：M5 输出闭环 + M1 会话编排器
   - **P2**：M6 口语栈 + M7 完整仪表
4. 每阶段的**验收标准**与主要风险。
5. **需要人工决策的开放问题清单**：至少覆盖 LLM 供应商与成本上限、TTS 方案与多说话人音源、M5 纠错提示词的评测方式。

## P0 验收标准（首个里程碑）

- 打开 app 零配置直接进入"今天的下一个动作"。
- 名词卡强制冠词+复数；FSRS 按 0.88 调度生效；交错调度可在日志中验证。
- 听写模式可用，句长爬坡规则生效，错误自动入错题卡。
- 完成 MVD 触发 streak；漏一天不清零；宽限日机制可验证。
