# 场景岛内容生成 Prompt(喂给各 LLM)

把下面 **「Prompt 正文」** 整段复制进任意 LLM(ChatGPT / Claude / Gemini / 通义 / DeepSeek 等),
先替换开头三个 `{{...}}` 占位,即可产出一个**严格符合 Echo 种子格式**的场景岛 JSON。

字段规则的权威来源是 [`seed-format.md`](./seed-format.md);本 Prompt 是它的"可执行"版本。

## 用法

1. 复制「Prompt 正文」全文。
2. 替换三个占位:
   - `{{目标语言}}` —— 要学的语言,如 `英语`、`德语`、`法语`。
   - `{{语言代码}}` —— 对应 BCP-47 代码,如 `en`、`de`、`fr`。
   - `{{场景主题}}` —— 这个岛的场景,如 `机场值机`、`看医生`、`租房`、`打车`。
3. 可选:把 `{{句子数量}}`(默认 10)和 `{{order}}`(这个岛的排序号)改成你要的值。
4. 发送,得到一段 JSON。
5. 把生成的 **island 对象**(`{ "name", "order", "sentences" }`)追加到 `public/seed/echo_seed_{{语言代码}}.json` 的 `islands` 数组**末尾**(切勿插中间,理由见 seed-format.md §5)。

## Prompt 正文(从这行下面开始复制)

````text
你是一名面向中文母语者的语言教学内容编辑。请为一款「句子岛 + 影子跟读 + 间隔重复」的语言学习 App 制作一个**场景岛**的内容数据。

# 本次任务参数
- 学习目标语言:{{目标语言}}(语言代码 {{语言代码}})
- 场景主题:{{场景主题}}
- 句子数量:{{句子数量}}(默认 10)
- 这个岛的排序号 order:{{order}}(默认 1)

# 输出要求(非常重要)
- **只输出一个 JSON 对象,不要任何解释、前言、Markdown 代码块标记。**
- 顶层就是这个岛对象,结构严格如下:
```
{
  "name": "<这个岛的中文场景名,如:打招呼>",
  "order": <整数,等于上面的 order>,
  "sentences": [ <句子对象数组,长度 = 句子数量> ]
}
```
- 每个**句子对象**必须且只能包含这些字段:
  - "native":这句话的**中文**意思,口语化、自然。
  - "target":对应的 **{{目标语言}}** 句子,选最地道、最常用的口语表达。
  - "frame":句型模板。用 `___` 标出可替换成分,括号里给中文或可选项提示。例:`"Good ___!(morning / afternoon / evening)"`。若整句无法套模板,就原样放主句并在括号里给简短中文提示。
  - "literal":**逐词直译成中文**(按词对照,体现 {{目标语言}} 的语序,不是通顺翻译)。例:Good morning → "好的 早晨"。
  - "note":中文用法说明(1~2 句):何时用、正式/随意、地区差异、易错点等。
  - "variants":**正好 5 条**其它说法的数组({{目标语言}}),覆盖正式↔随意、不同场合、常见变体;可在条目末尾用括号补中文提示。
  - "ipa":这句 "target" 的 IPA 音标(不带斜杠 `/`)。英语用通用美音;其它语言用标准发音。

# 内容质量要求
- 场景围绕「{{场景主题}}」展开,句子之间有真实对话/使用的连贯感,从最常用、最先会用到的开始排。
- 全部面向**口语实战**,不要书面腔、不要教科书例句。
- "target" 与 5 条 "variants" 不能重复,且都应是母语者真的会说的话。
- 标点、引号都用半角;字符串内如含双引号请正确转义。
- 不要输出 "id" 字段(程序会自动生成)。
- 不要把多个岛合并;本次只产出 1 个岛。

# 一个合格句子对象的示例(供格式参考,实际请按本次参数生成)
{
  "native": "可以看一下菜单吗?",
  "target": "Could I see the menu, please?",
  "frame": "Could I ___, please?(see the menu / order)",
  "literal": "可以 我 看 这 菜单,请",
  "note": "Could I 比 Can I 更礼貌;点餐场景很实用。",
  "variants": [
    "Can I have the menu, please?",
    "May I see the menu?",
    "Could we get the menu?",
    "Do you have a menu in English?",
    "What's on the menu today?"
  ],
  "ipa": "kʊd aɪ siː ðə ˈmɛnjuː"
}

现在,请按以上要求生成完整的岛 JSON。
````

(复制到这行上面为止)

## 校验生成结果

把生成的岛对象并入种子文件后,做一次最小校验:

```bash
node -e "require('./public/seed/echo_seed_{{语言代码}}.json')"   # 能 require 即 JSON 合法
pnpm build                                                       # 静态导出不报错、岛页面生成
```

逐项对照 [`seed-format.md` §4](./seed-format.md) 的字段表确认无误。若 LLM 多输出了解释文字或代码块标记,删掉只留纯 JSON。
