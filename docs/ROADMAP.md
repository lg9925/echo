## 当前路线图(按此顺序推进)

1. **稳定版**:补完收件箱/中间层 + 数据备份导出/导入 + 后台锁屏播放(MediaSession)
2. **整理**:重排信息架构,把音色/模型等设置收进高级设置(落实原则一)
3. **内容管理**:句子增删改/移动/重生成、拆岛、字词表、变体入词表
4. **画像 + 学习目标**:轻量用户画像优化生成 context;考级/书籍/行业目标
5. **随手助手**:常驻对话面板,随时"描述场景→生成岛"、随时提问
6. **高级开放 + 视觉打磨**:放开音色/模型/自带 key,进度防弃疗、录音对比,最后做视觉打磨
